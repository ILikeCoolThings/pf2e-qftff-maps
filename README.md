# PF2e Quest for the Frozen Flame Map Remakes (Books 2 & 3)

This is a simple module that includes some scenes for the PF2e adventure path: "Quest for the Frozen Flame". I found that the base maps weren't up to the quality I wanted, and also was an excuse to learn to make maps. The level of detail is all over the place... but I think they are better than the pixelated maps from the AP. 

**Hex maps and Calamtiy Caves are not included.** 
I started mapping after Calamity Caves in my campaign and will not be remaking it retroactively. You can find a remake made by someone else, though you will need to import and wall it in: https://inkarnate.com/m/wDjAzw-calamity-caves

The module does not contain any of the material or content from the book outside of the map remakes.
